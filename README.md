# Projeto-Python
Projeto da disciplina de Fundamentos de Algoritmos.
O sistema deveria permitir aos usuários buscar músicas, opções de
"curtir" e "descurtir", criar e editar playlists (adicionando ou removendo
músicas), excluir playlists existentes, visualizar músicas na playlist e
visualizar os históricos de músicas curtidas e descurtidas. Além de
funcionalidades de cadastro e login de usuários foram implementadas. Para
o desenvolvimento, foi utilizado a linguagem Python, utilizando arquivos de
texto simples (.txt) como meio de armazenamento persistente das
informações dos usuários, músicas, históricos e playlists.
